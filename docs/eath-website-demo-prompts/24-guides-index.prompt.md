## Profiles

Use guide-demo-01..03 only. Card: safe silhouette/illustrated placeholder, name, sample role, short biography excerpt, associated sample trek names where useful and View Profile. Empty languages/qualifications/years_experience must not become fabricated credentials. Do not use real people's photographs to represent these invented identities.

Desktop3 columns; tablet2; mobile1 with enough text space. Portrait ratios consistent, no shadow, no count-up counters. Human warmth can come from original demo copy and typography rather than fabricated reputation.

## Behavior

Profile links resolve by fixture slug. Associated treks use existing IDs. Start planner does not preassign a guide; a preference can be noted only as an unconfirmed sample request. Do not introduce a guide availability calendar.

## Acceptance

Three distinct profiles/cards, disclosure visible at card level, no fake languages/certificates/rating badges, safe empty-array rendering, route and image fallback tests, mobile/keyboard. All data from repository, not a separate hardcoded Blade array.
