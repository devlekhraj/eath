# Start in Antigravity

Copy the following into Antigravity with your existing Laravel project root open. No extension-specific rule format is assumed.

```text
We are building the complete EATH public-website demo in my existing Laravel project.

Read docs/eath-website-demo-prompts/README.md and docs/eath-website-demo-prompts/00-master-rules.prompt.md completely. Follow applicable repository instructions. This full-site demo pack supersedes the previous homepage-only pack for this task; do not remove the old pack or previous implementation.

Then execute ONLY docs/eath-website-demo-prompts/01-audit-and-route-map.prompt.md. Read the references it requires.

This first phase is read-only: inspect the project, identify real routes/templates/assets/versions and propose the /demo isolation plan. Do not edit application files, install dependencies, run migrations/seeders, submit forms or deploy. Never output credentials or environment values.

Return the required audit, actual-to-proposed route/template mapping, risks and safe verification commands. Stop and wait for my review before implementing phase 02.
```

After approval, use the phase command in [RUN-SEQUENCE.md](RUN-SEQUENCE.md). If changing from Codex to Antigravity mid-project, read the work log and do not replace completed components.
